# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-04-07

### Added
- Initial project setup with Next.js 14+ (App Router).
- GGH Standard Tech Stack: TypeScript, Tailwind CSS, TanStack Query, Zustand, Zod.
- Feature-based folder structure.
- Root layout with QueryProvider.
- GGH-themed home page.
- Project documentation (README.md, CHANGELOG.md).
- Vitest and React Testing Library for enterprise-grade unit and integration tests.
- Global error boundary (`error.tsx`) and custom 404 page (`not-found.tsx`).
- Environment variable validation using Zod.
- Sample `user` feature demonstrating the Service Layer and Zustand Store patterns.
- Prettier and Tailwind plugin for consistent code styling.
